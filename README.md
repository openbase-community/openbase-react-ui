# openbase-ui

Shared React component library for Openbase web frontends: product components, console pages, contexts, hooks, and a shadcn/Radix primitive kit, shipped as a single ESM package with type declarations.

## Contents

- `src/components/` — product components: `AgentChatPanel` (agent chat UI), `ProjectLayout` / `ProjectRoutesWithChat` (project shell + routing), and schema/introspection views (`ModelsView`, `ModelsRelationshipsView`, `SerializersView`, `TasksView`, `CodeView`, `WebAppView`).
- `src/components/ui/` — shadcn/Radix primitives (button, dialog, chart, table, …).
- `src/pages/` — project-console pages: `ProjectHome`, `ModelsPage`, `EndpointsPage`, `EndpointPage`, `CommandsPage`, `AdminPage`, `ProjectSettingsPage`.
- `src/contexts/` — `ProjectContext`, `AgentChatContext`.
- `src/hooks/` — `use-apps`, `use-chat-api`, `use-mobile`.
- `src/lib/` — API, emoji, and classname utilities.

## Usage

Only compiled output is published (`dist/`: ESM + `.d.ts`); import from the root barrel:

```ts
import { AgentChatPanel, ProjectLayout, useChatApi } from "openbase-ui";
```

All UI-framework dependencies (React, Radix, react-hook-form, recharts, …) are **peerDependencies** — the consumer provides them. Styling assumes Tailwind with the shadcn HSL design-token convention (`--background`, `--primary`, …).

## Developing

```bash
pnpm build   # barrelsby (regenerates index.ts barrels) + tsc + tsc-alias
pnpm dev     # watch mode: barrels + tsc + alias rewriting, concurrently
```

Barrel files (`index.ts`) are generated by barrelsby — edit source files, never barrels.

## Versioning

Semver in `package.json`. Multiple applications consume this package, so prefer backward-compatible changes; breaking changes fan out.
